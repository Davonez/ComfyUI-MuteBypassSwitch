ComfyUI 静音容错开关包 v1.7.0
========================================

解决什么问题
------------
把工作流里某个节点「静音 / 禁用」（选中后按 Ctrl+M）之后，它的输出线会在提交时消失，
下游节点的必填输入就没了，整个工作流直接报：

    Required input is missing

卡在那里跑不动。这几个开关就是插在中间用的：主线没了自动走旁路，
交出去的是原来那个对象 —— 不复制、不转换、不改动任何数据。

安装（30 秒）
-------------
1. 把 ComfyUI-MuteBypassSwitch 整个文件夹放进：
       <你的 ComfyUI 目录>\custom_nodes\
   （整合包一般就在 ...\ComfyUI-aki-vX\ComfyUI\custom_nodes\）
   两种拿法任选：
     git clone https://github.com/Davonez/ComfyUI-MuteBypassSwitch.git   （在 custom_nodes 里执行）
     或者下载 zip 解压进去
2. 重启 ComfyUI（关掉控制台窗口，再双击启动脚本）
3. 浏览器里按 F5 刷新一次页面
4. 双击画布搜索「汇聚 / 分发」，或右键 → Add Node → Switch，能看到下面五个节点

五个节点
--------
1) 多通道汇聚开关 (Multi Channel Switch)   ← 一条支路有多个产出时用这个
   每个通道各自挑「活着的哪一路」，通道数量自动增加：
   一个通道接满，就多出下一通道的 2 个输入口 + 1 个输出口（最多 8 通道）。
   不想自动挑？每个通道都有自己的下拉 ch1_force / ch2_force …（auto/a/b/c），
   也可以用一个总 force 一次把全部通道指定成 a / b / c。
   指定的那一路没值就输出空，不会偷偷替你去挑。
2) 多路汇聚开关 (Multi Any Switch)         ← 只要一路数据时用这个
   输入口想接几路接几路（最后一路接上会自动多一个空口），输出有值的那一路。
   同样有 force：填 0 = 自动挑，填 3 = 强制走第 3 路。
3) 静音旁路开关 (Mute Bypass Switch)
   主线 / 旁路两路，主线被静音就自动走旁路；带一个 switch 开关和一个 route 下拉。
4) 任意 A/B 开关 (Any A/B Switch)
   任意类型二选一，选中的那路没接就自动退回另一路。
5) 输出分发开关 (Output Fanout Switch)   ← 和多通道相反：一对多
   只有两个控件：①「每个输入配几个输出」（2 个 / 3 个 / 4 个）
                 ② 每个输出一个「开 / 关」
   接上 A 就出 2 个输出（选 2 个时），再接上 B 就变 4 个，自动跟 B。
   输出跟哪一路是自动配对的，不用选。最多 8 路输入。

要求
----
* 不需要 pip install，纯标准库。
* web 文件夹里的 .js 是「自动长输入口 / 自动加通道」的前端扩展，别删。
* ComfyUI 版本：2024 年底之后的都可以（用到 * 通配类型和 custom_nodes 的 WEB_DIRECTORY）。
